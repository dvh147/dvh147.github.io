A first post

2 September 2026

This is a template. To write a real post, copy this file to posts/YYYY-MM-DD-some-slug.html, change the <title>, the <h1> and the date, replace this text, and add three lines to writing.html pointing at the new file. That is the whole mechanism — there is no build step and nothing to install.

What you can use

Ordinary paragraphs, second-level headings like the one above, emphasis, bold, and links all work. So do lists:

  • An unordered list.
  • A second item.

Block quotations are styled too:

A decrease in air pollution equivalent to the average yearly drop in Europe leads to 1.2% more patented inventions in a given region.

Inline code and code blocks are available if you ever want to show a snippet:

ppmlhdfe patents pm25, absorb(region year) cluster(region)

Images go in assets/files/ and are inserted with <img src="/assets/files/chart.png" alt="...">. They scale down on small screens automatically.
